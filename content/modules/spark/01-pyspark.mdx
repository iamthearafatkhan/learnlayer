# Big Data with Apache Spark (PySpark)
When your data is too big for Pandas (e.g., Terabytes), you use Spark. PySpark is the Python API for Spark.

## 🎯 Core Concepts
- Distributed Computing concepts
- RDDs vs DataFrames
- Lazy Evaluation
- Spark SQL

## 📚 The Golden Path
1. **[Databricks: Free Spark Training](https://www.databricks.com/learn/training/home)**: The creators of Spark offer free training.
2. **[PySpark Tutorial (YouTube)](https://www.youtube.com/watch?v=_C8kWso4ne4)**: A great 1-hour crash course.
