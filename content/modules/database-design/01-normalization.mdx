# Database Design
As a DBA, you don't just query data; you design how it is stored. Bad design leads to slow apps and corrupted data.

## 🎯 Core Concepts
- Primary Keys and Foreign Keys
- Normalization (1NF, 2NF, 3NF) to remove duplicate data
- Entity-Relationship Diagrams (ERDs)
- Indexes (Speeding up lookups)
