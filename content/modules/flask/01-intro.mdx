# Flask (Python Web Framework)
Flask is a microframework. Unlike Django, it doesn't force you to use a specific database or structure. It's perfect for APIs and small apps.

## 🎯 Core Concepts
- Routes (`@app.route`)
- Jinja2 Templating (HTML rendering)
- HTTP Methods (GET, POST)
- APIs with JSON (`jsonify`)

## 📚 The Golden Path
1. **[Flask Official Quickstart](https://flask.palletsprojects.com/en/stable/quickstart/)**: Read this to understand routing.
2. **[Flask Mega-Tutorial](https://blog.miguelgrinberg.com/post/the-flask-mega-tutorial-part-i-hello-world)**: The most famous Flask tutorial in the world.
