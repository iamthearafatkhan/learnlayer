# NumPy for Data Science
NumPy is the foundation of all Python data science. It handles massive mathematical arrays faster than standard Python lists.

## 🎯 Core Concepts
- 1D and 2D Arrays (`np.array`)
- Vectorization (No more `for` loops)
- Broadcasting
- Mathematical functions (`np.mean`, `np.std`)
