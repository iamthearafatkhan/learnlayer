# Databases & ORMs
When building full-stack apps, you don't write raw SQL in your JavaScript/Python. You use an ORM (Object-Relational Mapper).

## 🎯 Core Concepts
- What is an ORM? (Prisma, Django ORM, SQLAlchemy)
- Migrations (Updating database schema safely)
- CRUD operations via code

## 📚 The Golden Path
1. **[Prisma Quickstart](https://www.prisma.io/docs/getting-started/quickstart)**: The modern standard for Node.js ORMs.
2. **[Django Models Docs](https://docs.djangoproject.com/en/stable/topics/db/models/)**: Learn how Django abstracts SQL.
