# PyTorch & Deep Learning
PyTorch is the go-to library for building Neural Networks (Deep Learning). It is used by top AI companies.

## 🎯 Core Concepts
- Tensors (Multi-dimensional arrays, like NumPy but on GPU)
- Autograd (Automatic differentiation)
- Building Neural Networks (`torch.nn`)
- Training Loops (Forward pass, Loss, Backward pass)

## 📚 The Golden Path
1. **[PyTorch Official Tutorials](https://pytorch.org/tutorials/)**: Start with "Learn the Basics".
2. **[Deep Learning with PyTorch (Free Book)](https://pytorch.org/assets/deep-learning/Deep-Learning-with-PyTorch.pdf)**: The official free book by the creators.
