# SQL Fundamentals

**SQL** is the #1 skill for Data Analysts. 90% of your day involves querying databases. You don't need to memorize everything; you just need to know how to ask the database the right questions.

## 🎯 Core Concepts to Master
- `SELECT`, `WHERE`, `GROUP BY`, `HAVING`
- `INNER JOIN`, `LEFT JOIN` (The most important!)
- `CASE WHEN` (For conditional logic)
- Window Functions (For advanced analytics)

## 📚 The Golden Path (Free Resources)
Follow these in order. Do not skip the practice exercises.

1. **[SQLBolt](https://sqlbolt.com/)**: The best interactive tutorial to learn the basics in your browser. (Takes 2 hours).
2. **[Mode Analytics SQL Tutorial](https://mode.com/sql-tutorial/)**: Excellent for learning how analysts actually use SQL in business.
3. **[LeetCode Database](https://leetcode.com/problemset/database/)**: Solve the "Easy" and "Medium" SQL problems to pass real job interviews.
