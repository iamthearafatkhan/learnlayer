# MongoDB (NoSQL)
MongoDB is a NoSQL database. Unlike SQL tables, it stores data in flexible, JSON-like documents.

## 🎯 Core Concepts
- Documents and Collections (instead of Rows and Tables)
- CRUD Operations (`insertOne`, `find`, `updateOne`, `deleteOne`)
- MongoDB Atlas (Cloud Hosting)
- Aggregation Pipeline (MongoDB's version of GROUP BY)
