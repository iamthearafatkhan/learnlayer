# Matplotlib
Matplotlib is the grandfather of Python visualization. It gives you total control over every pixel of your charts.

## 🎯 Core Concepts
- Line charts (`plt.plot`)
- Bar charts (`plt.bar`)
- Scatter plots (`plt.scatter`)
- Customizing titles, labels, and colors

## 📚 The Golden Path
1. **[Matplotlib Official Pyplot Tutorial](https://matplotlib.org/stable/tutorials/pyplot.html)**: The standard starting point.
2. **[Kaggle: Data Visualization](https://www.kaggle.com/learn/data-visualization)**: Learn to plot real datasets.
