# Java Programming
Java is the language of enterprise backend systems, Android apps, and massive scale applications (like Netflix and LinkedIn).

## 🎯 Core Concepts
- Object-Oriented Programming (Classes, Inheritance)
- Strong Typing (`int`, `String`, `boolean`)
- The JVM (Java Virtual Machine)
- Spring Boot (The most popular Java framework)
