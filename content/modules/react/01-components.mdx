# React Fundamentals
React is a JavaScript library for building user interfaces, maintained by Meta (Facebook). It is the most in-demand frontend skill.

## 🎯 Core Concepts
- Components and JSX
- Props and State (`useState`)
- Side Effects (`useEffect`)
- Conditional Rendering

## 📚 The Golden Path
1. **[React Official Tutorial](https://react.dev/learn)**: The new official docs are amazing. Read the "Quick Start".
2. **[Full Stack Open](https://fullstackopen.com/en/)**: A free course from the University of Helsinki.
