# Bash Scripting
Bash is the default shell on almost all Linux systems. You use it to write scripts that automate deployments, backups, and cron jobs.

## 🎯 Core Concepts
- Variables and Arguments (`$1`, `$2`)
- `if` statements and `for` loops
- Piping and redirection (`|`, `>`, `>>`)
- Cron jobs (Scheduling scripts)

## 📚 The Golden Path
1. **[Bash Scripting Tutorial](https://linuxconfig.org/bash-scripting-tutorial-for-beginners)**: A great comprehensive guide.
2. **[ShellCheck](https://www.shellcheck.net/)**: Paste your scripts here to find syntax errors.
