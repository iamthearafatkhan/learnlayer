# Python Fundamentals & Algorithms

Python is the most versatile language in the world. You will use it for data cleaning, machine learning, building web servers, and automation.

## 🎯 Core Concepts to Master
- Data Types (Lists, Dicts, Sets) & Loops
- Functions & Object-Oriented Programming (OOP)
- Time Complexity (Big O Notation)
- File I/O & Error Handling

## 📚 The Golden Path (Free Resources)
1. **[CS50P (Harvard's Python Course)](https://cs50.harvard.edu/python/)**: The absolute best free course on the planet. It covers everything from basics to OOP and File I/O.
2. **[NeetCode Roadmap](https://neetcode.io/roadmap)**: Once you know the basics, use this to master Data Structures & Algorithms (Sorting, Searching, Graphs, Dijkstra) for technical interviews.
3. **[Real Python Tutorials](https://realpython.com/)**: The best reference site for deep-diving into specific Python concepts.
