# Linux Command Line
Every server on the internet (including the one hosting this app) runs Linux. You must master the terminal.

## 🎯 Core Concepts
- Navigation: `ls`, `cd`, `pwd`
- File management: `cp`, `mv`, `rm`, `mkdir`
- Permissions: `chmod`, `chown` (The dreaded 777)
- Finding things: `grep`, `find`
