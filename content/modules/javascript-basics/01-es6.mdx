# JavaScript Fundamentals
Before React, you must know JavaScript. Specifically, modern JavaScript (ES6+).

## 🎯 Core Concepts
- Variables (`let`, `const`)
- Arrow Functions (`() => {}`)
- Array Methods (`map`, `filter`, `reduce`)
- Promises and `async/await` (Fetching data)

## 📚 The Golden Path
1. **[JavaScript.info](https://javascript.info/)**: The absolute best modern JS tutorial.
2. **[FreeCodeCamp: JavaScript Algorithms](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures/)**: Practice the basics.
