# Django (Python Web Framework)
Django is a "batteries-included" framework. It gives you an admin panel, database ORM, and security out of the box.

## 🎯 Core Concepts
- MVT Architecture (Model-View-Template)
- Django ORM (Writing Python instead of SQL)
- URL Routing & Views
- Authentication (Login/Register out of the box)

## 📚 The Golden Path
1. **[Django Official Tutorial](https://docs.djangoproject.com/en/stable/intro/tutorial01/)**: The best place to start. Build a polling app.
2. **[Django for Everybody (UMich)](https://www.dj4e.com/)**: Free university course by Dr. Chuck.
