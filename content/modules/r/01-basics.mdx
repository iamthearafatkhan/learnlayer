# R Programming
R is a language built specifically for statistics and data visualization. It is heavily used in academia, healthcare, and finance.

## 🎯 Core Concepts
- Vectors and DataFrames
- The `tidyverse` ecosystem (especially `dplyr` and `ggplot2`)
- Statistical testing (T-tests, ANOVA)

## 📚 The Golden Path
1. **[R for Data Science (Free Book)](https://r4ds.had.co.nz/)**: The absolute bible of R programming.
2. **[Swirl](https://swirlstats.com/)**: Learn R directly inside the R console.
