# Excel for Data Analysis
Excel is still the #1 tool used by businesses to view and manipulate data. You must master Pivot Tables and Lookups.

## 🎯 Core Concepts
- VLOOKUP / XLOOKUP (Merging data)
- Pivot Tables (Summarizing data)
- IF / Nested IF statements
- Data Cleaning (Text to Columns, Flash Fill)
