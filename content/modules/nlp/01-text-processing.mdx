# NLP (Natural Language Processing)
NLP is how AI understands text. It powers ChatGPT, sentiment analysis, and translation tools.

## 🎯 Core Concepts
- Tokenization (Splitting text into words)
- Stemming and Lemmatization
- Named Entity Recognition (NER)
- Using `spaCy` or `NLTK` libraries

## 📚 The Golden Path
1. **[Hugging Face NLP Course](https://huggingface.co/learn/nlp-course/chapter1/1)**: The best modern NLP course, entirely free.
2. **[Advanced NLP with spaCy](https://course.spacy.io/en/)**: Free interactive course by the creators of spaCy.
